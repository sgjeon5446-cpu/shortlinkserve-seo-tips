한국 소상공인 SEO 가이드

광고 없이 검색에서 손님을 만나는 기초. 작은 가게·1인 사업자가 직접 따라 할 수 있는 실용 가이드입니다.

1. 키워드는 손님의 언어로

전문가가 쓰는 단어와 손님이 검색창에 치는 단어는 다릅니다. "치과"가 아니라 "○○동 치과 추천" 같은 자연스러운 표현이 답입니다. 네이버 자동완성·연관검색어를 보면 실제 손님이 쓰는 단어가 나옵니다.

2. 모바일 우선 가벼운 페이지

검색 트래픽의 70% 이상이 모바일입니다. 무거운 홈페이지보다 메뉴·위치·연락처·예약만 담은 가벼운 랜딩페이지가 매출에 직결됩니다. 랜딩페이지 제작 서비스 같은 곳에서 한국형 SEO 구성을 자동으로 잡아 줍니다.

3. 정보의 일관성

가게 이름·주소·전화·영업시간이 구글 비즈니스 프로필·네이버 플레이스·홈페이지 어디서나 같아야 검색 신뢰를 얻습니다. 다르면 검색엔진이 의심합니다.

4. 후기와 사진이 곧 신뢰

별점·리뷰·답글이 일관되게 쌓인 가게는 검색 결과 상위에 노출됩니다. 메뉴·매장·실제 손님이 남긴 사진이 글 100줄보다 강력합니다.

5. FAQ로 검색 노출 늘리기

고객이 실제로 묻는 질문이 곧 검색 키워드입니다. "주차 되나요?" "예약 필수인가요?" 같은 진짜 질문을 모아 답하면 검색 결과에 그대로 노출됩니다.

6. 빠르게 시작하기

홈페이지 제작이 부담이라면 서브도메인 한 페이지로 즉시 시작 가능합니다. 서브도메인 호스팅으로 무료 SSL·모바일 최적화·SEO 기본 셋팅까지 자동으로 됩니다.
